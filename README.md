# AetherCircleExamples

<https://github.com/Zodiac-Innovations/AetherCircleExamples>

Example applications demonstrating the AetherCircle cross-platform immersive application framework.

## Repository Organization

Every example is stored as a top-level AetherCircle project. The repository intentionally uses a flat list rather than separate Samples and Showcases folders.

Each project contains an `AetherCircle.info` file, portable application code under `Shared/Swift`, shared resources under `Shared/Files`, and generated native platform projects when applicable.

## Examples

### HelloAetherCircle

A minimal introductory AetherCircle application for Apple Vision Pro. It demonstrates:

- A project title created from the application's display name.
- A rotating blue cube using a registered named material.
- A spatial Quit button with a Yes/No confirmation panel.
- Safe application termination through the AetherCircle platform service.
- An AVP Xcode project generated by the AetherCircle CLI.
- File-system-synchronized `Shared/Swift` and `Shared/Files` folders, allowing new source and resource files to appear in Xcode automatically.

Open the example with:

```bash
cd HelloAetherCircle
aethercircle doctor
aethercircle avp ide
```

Regenerate its AVP project after changing project metadata or after a generator update:

```bash
aethercircle avp create -d
```

## Creating Another Example

Install the current development CLI from `AetherCircleDevelopment`, then create the new project at the repository root:

```bash
aethercircle create ExampleName \
    --display-name "Example Name" \
    --key com.zodiacinnovations
cd ExampleName
aethercircle avp create
```

Keep each example self-contained at the repository root and add a description to the Examples section of this README.

## Requirements

- macOS with the required Xcode and visionOS SDK
- XcodeGen
- The current AetherCircle command-line tool
- The AetherCircle Swift package accessible to the generated platform project

Run `aethercircle doctor` to check the local development environment and project.
