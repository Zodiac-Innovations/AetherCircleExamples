# AetherCircleExamples

<https://github.com/Zodiac-Innovations/AetherCircleExamples>

Example applications demonstrating the AetherCircle cross-platform immersive application framework.

## Repository Organization

Every example is stored as a self-contained, top-level AetherCircle project.

An example can include:

- `AetherCircle.info` for portable project metadata.
- `Shared/Swift` for cross-platform application code.
- `Shared/Files` for shared runtime assets.
- `Shared/Icons` for source application icons.
- `Screenshots` for reference images of the running example.
- Generated native platform projects, such as `AVP`, when applicable.

## Examples

### HelloAetherCircle

The canonical Hello example and an unmodified copy of the AetherCircle **Starter** produced for a new project. It documents and validates exactly what a developer receives from the CLI before making application-specific changes.

The Starter demonstrates:

- A passthrough immersive environment.
- A title generated from the application's display name.
- A rotating blue cube using a registered named material.
- A spatial Quit button with confirmation.
- Safe application termination through the AetherCircle platform service.
- An Apple Vision Pro Xcode project generated by the AetherCircle CLI.
- File-system-synchronized `Shared/Swift` and `Shared/Files` folders, allowing new source and resource files to appear in Xcode automatically.
- Shared application-icon sources and screenshots of the generated application.

Because this example is intentionally unmodified, improvements to it should be made in the AetherCircle Starter generator first and then reproduced by regenerating `HelloAetherCircle`.

Open the example with:

```bash
cd HelloAetherCircle
aethercircle doctor
aethercircle avp ide
```

Regenerate its AVP project after changing project metadata or after a generator update:

```bash
aethercircle avp build -d
```

### AetherCircleShowcase

A multi-scene catalog demonstrating the principal AetherCircle objects, controls, materials, and navigation patterns. Its Home scene provides entry points for three focused demonstrations:

- **Primitive Objects** displays every visible Aether primitive in a labeled grid, combining randomly selected colors and textured materials with continuous three-axis rotation.
- **Panel Objects** demonstrates standard and double-sided buttons, message and Yes/No helper panels, multi-page content, Boolean controls in default, checkbox, radio-group, and switch styles, and an integer slider.
- **Materials** randomly selects three textured materials and three visible primitive shapes each time the scene opens, then displays the labeled, rotating results.

The Showcase also demonstrates named color and texture-material registration, physically based roughness and metallic settings, reusable title and Home controls, composite objects, golden target highlighting, scene navigation, passthrough presentation, and the standard confirmed Quit control. Its shared files include the texture catalog used by the Materials demonstration, while its screenshots provide visual references for the Home, Primitive Objects, and Materials scenes.

Open the example with:

```bash
cd AetherCircleShowcase
aethercircle doctor
aethercircle avp ide
```

Regenerate its AVP project after changing project metadata or after a generator update:

```bash
aethercircle avp build -d
```

## Creating Another Example

Install the current development CLI from `AetherCircleDevelopment`, then create the new project at the repository root:

```bash
aethercircle create ExampleName \
    --display-name "Example Name" \
    --key com.zodiacinnovations
cd ExampleName
aethercircle avp build
```

Keep each example self-contained at the repository root and add a description to the Examples section of this README. Reserve `HelloAetherCircle` as the unmodified reference output of the current Starter.

## Requirements

- macOS with the required Xcode and visionOS SDK
- XcodeGen
- The current AetherCircle command-line tool
- The AetherCircle Swift package accessible to the generated platform project

Run `aethercircle doctor` to check the local development environment and project.
